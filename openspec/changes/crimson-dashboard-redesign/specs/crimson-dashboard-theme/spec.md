## ADDED Requirements

### Requirement: Crimson Red Active Navigation Pill & Primary Buttons
The application SHALL render active sidebar navigation items and primary buttons using a solid Crimson Red background (`bg-rose-600` / `#E11D48`) with crisp white text (`text-white`) and a distinct shadow glow.

#### Scenario: Navigating application pages
- **WHEN** user is on any active page or views primary action buttons
- **THEN** system highlights the active sidebar menu pill with solid Crimson Red (`bg-rose-600 text-white font-bold shadow-md shadow-rose-600/30`) and styles all primary buttons in vibrant solid Crimson Red.
